# Data Coverage Analysis

## Objetivo

Determinar desde qué año existe suficiente cobertura de:

- Estadísticas de servicio
- Estadísticas de break points
- Duración de partidos

para utilizar esos datos en el motor analítico.

## Métricas evaluadas

- minutes
- ace
- df
- svpt
- first_in
- first_won
- second_won
- bp_saved
- bp_faced

## Output

data/parquet/data_coverage_by_year.parquet
