# Surface Metrics

## Objetivo

Generar métricas agregadas por:

- Jugador
- Superficie

## Input

data/parquet/player_matches.parquet

## Output

data/parquet/player_surface_metrics.parquet

## Métricas

- matches
- wins
- losses

- aces_per_match
- double_faults_per_match

- first_serve_in_pct
- first_serve_won_pct
- second_serve_won_pct

- bp_saved_pct

- avg_minutes

## Uso

Motor analítico prepartido.
